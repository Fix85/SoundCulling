# Sound Culling

A client-side Fabric mod for Minecraft 1.21.11 that lets you block individual sound events in-game via Cloth Config and Mod Menu. Mute annoying, spammy, or unnecessary sounds (like specific mob, block, or UI sounds) without touching your resource packs or volume sliders.

## Features
- **Dynamic Sound Registry**: Lists all registered sound events dynamically (including those added by other mods!).
- **Quick Controls**: Mute or un-mute every sound in one click.
- **Custom Selection**: Fine-tune exactly which sounds to block and which to keep.
- **Lightweight**: Cancels blocked sounds before they are queued for playback.

## Requirements
- **Minecraft** 1.21.11
- **Fabric Loader**
- **Fabric API**
- **Cloth Config API** (Included / Required)
- **Mod Menu** (Highly Recommended to access the config screen)
